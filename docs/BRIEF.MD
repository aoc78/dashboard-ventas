# Brief: Dashboard de ventas
## Problema
El cliente registra ventas en Excel y no ve resultados de un vistazo.
## Alcance (lo que SÍ incluye)
- Subir archivo CSV/Excel con columnas: fecha, producto, cantidad, precio
- KPIs: ventas totales, número de ventas, ticket promedio
- Gráfica de ventas por mes y ranking de top 5 productos
- Funciona en celular y computador
## Fuera de alcance (lo que NO incluye)
- Usuarios y login, base de datos permanente, edición de datos
## Criterios de aceptación
- Con el archivo de ejemplo, los totales coinciden con un cálculo manual
- Un archivo mal formateado muestra un error claro, no se rompe
- Carga en menos de 3 segundos con 5.000 filas
## Entregables
- URL pública, código en GitHub, README, manual de uso de 1 página
